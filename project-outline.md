# Medical Diagnosis AI Project Outline

## Datasets
1. Dementia (MRI features)
2. Parkinson's Disease (voice features)

## AI Methods to Implement
- Discrete Bayesian Networks
- Gaussian Bayesian Networks
- Gaussian Processes

## Key Tasks
1. Data preprocessing and formatting
2. Model training (parameter inference)
3. Inference (answering probabilistic queries)
4. Model evaluation and comparison

## Implementation Steps
1. Data loading and exploration
2. Data preprocessing (including discretization if needed)
3. Feature selection/engineering
4. Model implementation
5. Training pipeline with cross-validation
6. Inference pipeline
7. Evaluation metrics calculation
8. Results analysis and comparison

## Considerations
- Use at least one dataset, justify the choice
- Implement methods to answer probabilistic queries
- Use appropriate feature values (discrete or continuous)
- Employ cross-validation (K=5 recommended)
- Compare methods using consistent metrics across datasets
- Focus on specific aspects like comparing discrete vs continuous methods or analyzing different structure learning algorithms

## Evaluation
- Use appropriate metrics for model comparison
- Critically appraise the strengths and weaknesses of each technique
- Justify the selection of methods for particular roles

## Deliverables
1. Python implementation of the chosen AI methods
2. Analysis of results and method comparisons
3. Critical appraisal of AI techniques used
4. Justification for method selection
