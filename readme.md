# Probabilistic Models for Dementia and Parkinson’s

Compare Bayesian networks and Gaussian process classifiers on dementia and Parkinson’s datasets.

Four notebooks cover two model families and two classification tasks. The dementia dataset includes MRI-derived measurements and clinical variables. The Parkinson’s dataset contains voice features. The notebooks explore classification on these datasets.
